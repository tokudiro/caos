# caos
C-language additional object-oriented source
English | [日本語](README.ja.md)

## Description
object-oriented source transpiler for C-language.
It implements only my minimum necessary functions .

---
## Build
build environment : gcc + flex

``` make ```

## Self-hosting
The classes of caos itself (`Caos`, `SBuf`, `RBuf`, `ListBuf`, `Element`, `SLib`) are written in `src/*.caos` and generated by caos.
The generated `.c` / `.h` files are committed, so caos can be built without caos.
After editing a `.caos`, run `make regen`; `make test` checks that the committed files match what caos generates.
The lexer (`src/*.l`, `src/prolog.c`) and `main.c` are written in C / flex.

## Sample Code

* SampleClass.caos

```c
#include <stdio.h>
#class $SampleClass

#@ int publicMember;
int privateMember;

#+int publicMethod(void){
    @privateMethod();
    return @privateMember;
}

#-void privateMethod(){
    @privateMember = 2 + @publicMember;
    return;
}

#endclass

SampleClass obj_impl;

int main(){
    $SampleClass obj = &obj_impl;
    SampleClass_set_publicMember(obj, 1);
    printf("%d\n", SampleClass_get_publicMember(obj) );
    printf("%d\n", SampleClass_publicMethod(obj) );
}
```

## Test
``` make test ```

Each `test/*.caos` is translated, compared with the snapshot in `test/expected/`, compiled with gcc and run.
After an intended change of the output, regenerate the snapshots with `UPDATE=1 sh test/test.sh` and review `git diff`.

## Directives
| directive | meaning |
|---|---|
| `#class $Name` ... `#endclass` | define a class (`#struct`, `#singleton`, `#utility` are variants) |
| `#+` / `#public` | public method |
| `#-` / `#private` | private method |
| `##` | protected method |
| `#$` / `#classmethod` | class method (no `this` pointer) |
| `#@` | public member (getter / setter are generated) |
| `#import` | include |
| `@name` | member or method of the current object (`pthis->name` / `Class_name(pthis)`) |

## Options
| option | meaning |
|---|---|
| `-h` | help |
| `-V` | verbose |
| `-L` | do not output line numbers |
| `-C` | replace `//` comments with `/* */` |
| `-k <str>` | change the this-pointer name (default `pthis`) |
| `-p` | do not output the private header |
| `-d` | do not output the define header |
| `-o <path>` | output folder (default: the folder of the input file) |

## Sample Output
* SampleClass.c

```c
#include <stdio.h>

#include "SampleClass_define.h"
#include "SampleClass_private.h"

int SampleClass_get_publicMember(const SampleClass* pthis) { return pthis->publicMember; }
void SampleClass_set_publicMember(SampleClass* pthis, int publicMember) { pthis->publicMember = publicMember; }

int SampleClass_publicMethod(SampleClass* pthis){
    SampleClass_privateMethod(pthis);
    return pthis->privateMember;
}

void SampleClass_privateMethod(SampleClass* pthis){
    pthis->privateMember = 2 + pthis->publicMember;
    return;
}

SampleClass obj_impl;

int main(){
    SampleClass* obj = &obj_impl;
    SampleClass_set_publicMember(obj, 1);
    printf("%d\n", SampleClass_get_publicMember(obj) );
    printf("%d\n", SampleClass_publicMethod(obj) );
}
```
