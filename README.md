# caos
C-language additional object-oriented source
English | [日本語](README.ja.md)

## Description
object-oriented source transpiler for C-language.
It implements only my minimum necessary functions .

## Design policy
caos is for small systems that have only a C compiler.
The rules below apply to the **generated C code**. The translator itself runs on a PC and is not bound by them.

* Readable output: the generated C reads like hand-written C. Names are plain (`Class_method`), `#line` points back to the `.caos` source, and no helper code is added behind the scenes.
* No hidden runtime: the generated code does not need a runtime library, and does not depend on libc.
* No dynamic allocation: the generated code does not call `malloc`. Objects can be allocated statically.
* Nothing implicit: nothing is generated unless the source asks for it (no implicit instantiation, no automatic constructor / destructor).
* Minimum features: a feature is added only when it is needed, and only if it satisfies the rules above.

## Self-hosting
The classes of caos itself (`Caos`, `SBuf`, `RBuf`, `ListBuf`, `Element`, `SLib`) are written in `src/*.caos` and generated by caos.
The generated `.c` / `.h` files are committed, so caos can be built without caos.
After editing a `.caos`, run `make regen`; `make test` checks that the committed files match what caos generates.
The lexer (`src/*.l`, `src/prolog.c`) and `main.c` are written in C / flex.
See the [class diagram](doc/class_diagram.md).
The syntax, the memory conventions and the error handling are described in the [language reference](doc/language.md).

## Sample Code

* SampleClass.caos

```c
#include <stdio.h>
#class $SampleClass

#@ int publicMember;
int privateMember;

#+int publicMethod(void){
    @privateMethod();
    return @privateMember;
}

#-void privateMethod(){
    @privateMember = 2 + @publicMember;
    return;
}

#endclass

SampleClass obj_impl;

int main(){
    $SampleClass obj = &obj_impl;
    SampleClass_set_publicMember(obj, 1);
    printf("%d\n", SampleClass_get_publicMember(obj) );
    printf("%d\n", SampleClass_publicMethod(obj) );
}
```

Each `test/*.caos` is translated, compared with the snapshot in `test/expected/`, compiled with gcc and run.

## Directives
| directive | meaning |
|---|---|
| `#class $Name` ... `#endclass` | define a class (`#struct`, `#singleton`, `#utility` are variants) |
| `#+` / `#public` | public method |
| `#-` / `#private` | private method |
| `#$` / `#classmethod` | class method (no `this` pointer) |
| `#@` | public member (getter / setter are generated) |
| `#interface $Name` ... `#endinterface` | interface (a table of function pointers); a class says `#class $X implements $Name` |
| `#class $Name<T>` ... / `#instance $X = $Name<int>` | template and its explicit expansion |
| `#require expr` / `#ensure expr` | precondition / postcondition of a method, checked with `CAOS_REQUIRE` / `CAOS_ENSURE` (`include/caos_contract.h`) |
| `#invariant expr` | condition of the class, checked on entry and exit of the public methods (`#noinvariant` leaves out the entry check) |
| `#import` | include |
| `@name` | member or method of the current object (`pthis->name` / `Class_name(pthis)`) |

## Options
| option | meaning |
|---|---|
| `-h` | help |
| `-V` | verbose |
| `-L` | do not output line numbers |
| `-C` | replace `//` comments with `/* */` |
| `-k <str>` | change the this-pointer name (default `pthis`) |
| `-p` | do not output the private header |
| `-d` | do not output the define header |
| `-o <path>` | output folder (default: the folder of the input file) |
| `-M <file>` | write a make dependency file (see below) |

## Build integration
`-M <file>` writes a dependency rule in make syntax, like `gcc -MF`:

```
A.c A.h A_private.h A_define.h : A.caos B.h
```

* The left side lists the files written, reflecting `-p`, `-d`, `-o` (and `#struct`, which has no define header).
* The right side is the input and the headers named by `#import $Name` or `#import "x.h"` (looked for next to the output, like the `#include` that is generated). `#import <x.h>` is not listed.

A Makefile for your project:

```make
CAOS    ?= caos
CFLAGS  += -MMD
CLASSES := $(basename $(wildcard *.caos))
OBJS    := main.o $(addsuffix .o,$(CLASSES))

app : $(OBJS)
	$(CC) -o $@ $^

# A class is translated into X.c, X.h, X_define.h and X_private.h at once.
# -M writes X.cd: the generated files depend on X.caos and on the #imported headers.
# (not X.d, which is the gcc -MMD file of X.o)
%.c : %.caos
	$(CAOS) -L -M $*.cd $<

# translate every class before compiling anything, so that the headers exist
$(OBJS) : | $(addsuffix .c,$(CLASSES))

-include $(addsuffix .d,$(basename $(OBJS))) $(addsuffix .cd,$(CLASSES))
```

`caos`'s own `Makefile` takes its class list from `src/*.caos` (`make regen`).

## Sample Output
* SampleClass.c

```c
#include <stdio.h>

#include "SampleClass_define.h"
#include "SampleClass_private.h"

int SampleClass_get_publicMember(const SampleClass* pthis) { return pthis->publicMember; }
void SampleClass_set_publicMember(SampleClass* pthis, int publicMember) { pthis->publicMember = publicMember; }

int SampleClass_publicMethod(SampleClass* pthis){
    SampleClass_privateMethod(pthis);
    return pthis->privateMember;
}

void SampleClass_privateMethod(SampleClass* pthis){
    pthis->privateMember = 2 + pthis->publicMember;
    return;
}

SampleClass obj_impl;

int main(){
    SampleClass* obj = &obj_impl;
    SampleClass_set_publicMember(obj, 1);
    printf("%d\n", SampleClass_get_publicMember(obj) );
    printf("%d\n", SampleClass_publicMethod(obj) );
}
```

* SampleClass.h

```c
#ifndef __SAMPLECLASS_H__
#define __SAMPLECLASS_H__
typedef struct SampleClass_struct SampleClass;
int SampleClass_get_publicMember(const SampleClass* pthis);
void SampleClass_set_publicMember(SampleClass* pthis, int publicMember);
int SampleClass_publicMethod(SampleClass* pthis);
#endif /* __SAMPLECLASS_H__ */
```

* SampleClass_define.h

```c
#include "SampleClass.h"
struct SampleClass_struct{

};
```

* SampleClass_private.h

```c
static void SampleClass_privateMethod(SampleClass* pthis);
```
